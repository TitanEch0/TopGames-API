TopGames-API Java Client

Version 1.1.0

1. Introduction

The TopGames-API Java Client is a robust, thread-safe, and feature-rich library designed to interact with the Top-Games.net REST API. It simplifies the integration of voting systems, server statistics retrieval, and player ranking analysis into your Java applications.

Key Features

  • Fluent Builder API: Easy and readable configuration.
  • Asynchronous Support: Non-blocking operations using CompletableFuture.
  • Resilience: Built-in automatic retries with exponential backoff.
  • Performance: HTTP caching and connection pooling via OkHttp.
  • Rate Limiting: Client-side rate limiting to respect API quotas.
  • Extensibility: Support for custom interceptors.

3. Getting Started

To start using the library, you need to instantiate the TopGamesClient. The only required parameter is your API Key (Server Token).

import xyz.titanecho.topgamesapi.TopGamesClient;

// Initialize the client
TopGamesClient client = new TopGamesClient.Builder()
    .apiKey("YOUR_SERVER_TOKEN")
    .build();
Note: The client implements AutoCloseable. It is recommended to use it within a try-with-resources block or call close() when the application shuts down to release resources.

4. Advanced Configuration

The builder allows you to configure various aspects of the client to suit your needs.

TopGamesClient client = new TopGamesClient.Builder()
    .apiKey("YOUR_SERVER_TOKEN")
    // Limit to 5 requests per second
    .rateLimit(5, Duration.ofSeconds(1))
    // Retry failed requests up to 3 times
    .enableRetries(3)
    // Cache responses for better performance
    .enableHttpCache(new File("./cache"), 10) // 10 MB cache
    // Enable detailed logging for debugging
    .enableDebugLogging()
    .build();

5. Server Information

Retrieve information about your server, including statistics and rankings.

Get Basic Info

Server server = client.getServerInfo();
System.out.println("Name: " + server.getName());
System.out.println("Votes: " + server.getVotes());

Get Full Info & Stats

Server fullInfo = client.getFullServerInfo();
for (Stat stat : fullInfo.getStats()) {
    System.out.println(stat.getDate() + ": " + stat.getVotes() + " votes");
}

Get Player Rankings

// "current" or "lastMonth"
List<PlayerRanking> ranking = client.getPlayersRanking("current");
ranking.forEach(p -> System.out.println(p.getUsername() + ": " + p.getVotes()));

6. Vote Management

Check and claim votes to reward your players.

Get Unclaimed Votes

List<Vote> votes = client.getUnclaimedVotes();
votes.forEach(v -> System.out.println("New vote from: " + v.getUsername()));

Check Vote Status

boolean hasVoted = client.checkVoteByIP("192.168.1.1");
// or
client.checkVoteByUsernameAsync("PlayerOne")
      .thenAccept(voted -> System.out.println("Voted: " + voted));

Claim Votes

try {
    client.claimVoteByUsername("PlayerOne");
    // or
    client.claimVoteBySteamId("76561198000000000");
    System.out.println("Vote claimed!");
} catch (TopGamesException e) {
    System.err.println("Error: " + e.getMessage());
}

7. Asynchronous Usage

All API methods have an asynchronous counterpart (suffixed with Async) that returns a CompletableFuture.

client.getServerInfoAsync()
    .thenAccept(server -> {
        System.out.println("Async loaded: " + server.getName());
    })
    .exceptionally(ex -> {
        ex.printStackTrace();
        return null;
    });

8. Error Handling

The library throws a checked TopGamesException for all API-related errors.

  • Network Errors: Connection timeouts, DNS issues.
  • API Errors: 4xx (Client Error) or 5xx (Server Error) HTTP responses.
  • Parsing Errors: Invalid JSON responses.
